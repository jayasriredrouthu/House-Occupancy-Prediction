House Occupancy Prediction

A Machine Learning case study that predicts whether a room is occupied or not using sensor data.

Algorithms Used

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)

Input Features

- Temperature
- Humidity
- Light
- CO2
- Humidity Ratio

Tools & Libraries

- Python
- Pandas
- Matplotlib
- Scikit-learn

Project Workflow

- Dataset loading and inspection
- Missing value checking
- Training and testing split
- Model training and comparison
- Accuracy evaluation
- Confusion matrix
- New sample prediction
